# 选项长度平衡（B11 欠账）批次表 — 2026-11-20

## 为什么做

## 改什么、不改什么

**只改选项措辞。** 答案键（`correct_answer`）、题干、解析、题目 id、难度、能力线一律不动。

两种改法，优先第一种：

1. **加长干扰项**——给干扰项补上它本来就该有的限定语，让它读起来像一个真选项，而不是一个标签。
2. **缩短正确项**——只砍掉不承载答案的修饰语，砍完仍然只有它成立。

### 硬规则

- 干扰项加字之后**必须仍然是错的**。不能补成「部分成立」「视情况而定」。
- 不许凑字数（「等等」「之类」「啊」「吧」）；四个选项要像同一个老师写的。
- 四个选项保持同一种句式（都是短语 / 都是完整句 / 都是释义）。
- 目标：**至少一个干扰项不短于正确项**；顺手能把最长/最短压到 1.5 倍内就压，压不动不勉强。
- 题干里逐字引用了某个选项的题（辨析题）不要动那个选项——脚本会拒。

## 工具

```bash
# 看某节点的待改清单（含每题长度、gap、band、解析）
python3 knowledge-eval/scripts/option_audit.py --subject chinese --node chinese-6up-d07 --emit

# 校验一份补丁（写错会 FAIL；改完仍不平衡也会 FAIL）
python3 knowledge-eval/scripts/patch_options.py --subject chinese --patch <file>.jsonl --dry-run

# 应用（由主代理串行执行，避免并行写同一个题库）
python3 knowledge-eval/scripts/patch_options.py --subject chinese --patch <file>.jsonl

# 复查
python3 knowledge-eval/scripts/option_audit.py --strict
```

补丁格式，一行一题，`o` 是**完整的四个选项**（没改的照抄）：

```json
{"q":"chinese-6up-d20-q05","o":["先读懂句子的意思，再按意思断开","按字数平均分成几段，每段一样长","读到哪里喘不上气就在哪里停","遇到不认识的字就先停一下再说"]}
```

`patch_options.py` 会拦：改答案键、改选项数量、选项重复、题干引用了被改的选项、**改完仍不平衡**。

### 两类不适用 B11 的题（豁免）

修的过程中发现 B11 不能一刀切，有两类的长度差**本身就是被考的点**，加字等于改答案：

1. **词形题**（英语 8 题）：`go swimming` 必然比 `go swim` 长，`bottles; pieces` 必然比 `bottle; piece` 长，`will be` 必然比 `will` 长。把干扰项补长就是把它改成对的。
2. **纯数值题**（数学 190 题、英语 12 题）：`8 / 4 / 16 / 2`、`3/7 + 5` 对 `3/7 + 3/7 + 3/7 + 3/7 + 3/7`。这里的"最长"是在数位数，不是在读措辞，孩子不会这么用。第一版把 `8` 改成 `n = 8`，结果正确项 `16` 成了唯一最短，反而造出新的异类信号 —— 已经撤掉。

还有 1 题（`english-6up-d02-q11`）题干问"下面表达**最完整**、最自然的一项是"——"最完整"本身就把长度当判据，改选项改不掉，除非改题干。留作已知例外。

### 一个还没消掉的次生信号

英语改后"猜最短"29%（随机 25%），因为干扰项普遍被补得比正确项长。语文、数学两端的命中率都是 15% / 25%，基本对称。29% 只比随机高 4 个百分点，够不上一个可利用的规律，但下次改写时应当**先在节点内分配名次**（正确项在长度上排第 1/2/3 的各占三分之一），而不是每题都往"干扰项更长"一个方向推。
