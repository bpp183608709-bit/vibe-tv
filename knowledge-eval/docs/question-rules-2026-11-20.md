# 生题硬约束（2026-11-20，M1–E6 共 16 批的教训汇总）

这份文件是**写题前的唯一清单**。它不解释题库怎么设计（那是 `ability-mastery-2026-11-19.md`），
只回答一件事：**下一批题在什么条件下一定会被打回**。

分三层：

| 层 | 含义 | 违反了会怎样 |
|---|---|---|
| **A 机器拦** | 门禁脚本直接失败 | 写不进库，或写完门禁红 |
| **B 人读** | 门禁看不见，只能靠写的人自觉 | 题进库了，但孩子做不出来 / 有两个答案 / 和课本对不上 |
| **C 待自动化** | B 里可以变成 A 的三条 | 目前仍靠人 |

A 层不用背，跑脚本就行；**B 层才是这份文件存在的理由**——16 批里所有返工都发生在 B 层，
没有一次是 A 层漏掉的。

---

## 0. 每批的三个动作

```
开工前  check_ability_coverage.py --subject X --detail   # 这批缺哪些格，别按估算
        看同节点存量题：占的是哪条线、用的什么句式
写题时  照 §2 的十条自检；数学先写 c 再写题干
提交前  batch_spec --dry-run → 写入 → 四门禁 → pytest → acceptance → 一提交
```

**上限**：单批 ≤40 题、≤16 格。超了就拆（C1a/C1b、E1a/E1b 都是这么拆出来的）。

## 1. A 层：机器拦（不能绕过，也不用记）

### 1.1 结构与格子

| 约束 | 报错关键词 | 在哪 |
|---|---|---|
| 节点的 `ability_lines` 非空、不重复、必须是本科允许的线 | `must declare ability_lines` / `not one <subject> uses` | `check_content.py` |
| 题的 `ability_tag` 必须 ∈ 该节点声明的线 | `would land in a cell the node never claims` | 同上 + `batch_spec.py` |
| `diagnostic_node_id` 必须是诊断节点 | `is not a diagnostic node` | 同上 |
| **每格 ≤ 9 题**（3 易 + 3 中 + 3 难） | `<node>/<tag>: N questions in one cell` | `MAX_PER_CELL = 9` |
| 每节点 ≤ 线数 × 9 | `N questions, want at most M` | 派生上限，不写死 |
| 聚合节点：`parent_id` null、无 `knowledge_type`、无 `ability_lines`、无先修 | `an aggregate must have parent_id null` 等 | `check_content.py` |
| 诊断节点的 parent 必须是聚合 | `parent ... is not an aggregate` | 同上 |

> `MAX_PER_CELL` 已经改过三代（18/学科 → 6/节点 → 6/格 → 9/格）。**它是判档窗口的派生物，不是审美**：
> 窗口 `MASTERY_WINDOW = 10`，每格 9 题才填到 90%。改规格必须同步改这个常量，否则门禁会拦住合法的题。

### 1.2 题干与答案

| 约束 | 报错关键词 |
|---|---|
| 题干 **≤ 120 字符**（按整串算，含「读句子：“…”」那部分） | `stem is N characters, over 120` |
| 全库题干不得重复（空白归一后比较，跨科跨批都查） | `repeats the stem of` |
| 本批内题干也不得重复 | `the same stem already appears on this spec line` |
| 选择题 ≥2 项；判断题恰好 2 项；答案 ∈ 实际标号范围 | `a judgement item needs exactly two options` 等 |
| 选项不得两项一模一样 | `two options are identical` |
| **填空题只有数学能用**（电视遥控器没有字母键） | `<subject> cannot use a fill` |
| 填空的 `accepted[0]` 必须等于 `correct_answer`，且必须是数字或分数 | `must equal accepted[0]` / `is not a number or fraction` |
| 选择题不得携带 `accepted` | `a choice must not carry accepted strings` |
| 单批选择题 ≥6 道时，任一标号占比 **>60% 直接拒批** | `answer spread: B holds 9/15` |
| spec 未知字段、缺必填字段一律拒 | `unknown key(s)` / `\`x\` is required` |
| 一行坏 → **整批不写**（原子） | `nothing written` |

> 答案分布门禁只在 `batch_spec.py`（写入时）生效，`check_content.py` 不查存量偏斜。
> 存量偏斜要单独做一次重排（语文 C1 前、英语 E1 前各做过一次）。

### 1.3 数学的 `c` 字段

| 约束 | 说明 |
|---|---|
| 填空**必须**有 `c`，且 `c` 要**算出答案本身** | 写 `Fraction(5,6)*3`，不能写 `5/2 == 5/2` 这种恒真式 |
| 选择题有 `c` 时，`c` 必须求值为 `True` | 写「使正确选项正确的那个计算」，不是复述标号 |
| `c` 是数学专用 | 语文英语带 `c` 直接拒 |
| 覆盖率只打印不强制 | 「方向」类题没有算术，强行要求会写成废话；但一批掉到 20/30 以下要看一眼 |

### 1.4 解析

| 约束 | 报错关键词 |
|---|---|
| **非数学的解析不得用裸 A/B/C/D 指代选项** | `explanation points at options by letter` |
| 「字母 A」这种讲字母本身的写法放行 | — |
| 数学豁免 | 那里 A/B/C 是图中点的名字，`C` 还是周长符号（`C = 2πr`） |

> 这条是为「选项轮转」服务的：选项一动，解析里的字母就指到别的选项上，**文件里看不出任何异常**，
> 只有孩子会看到一个错理由。

### 1.5 课本对齐（outline）

| 约束 | 报错关键词 |
|---|---|
| 题干/选项里 `《…》` 的标题必须是课本里有的 | `quotes 《X》, which is not in the outline` |
| 已退役篇名（换教材后离开本册的）**任何位置**不得出现，带不带书名号都算 | `still names 'X', which left this volume` |
| 单元名、章节序必须等于课本印刷值（数学/英语） | `node name ... is not the book's` |
| `assessable: false` 必须写 `reason`；`true` 不许带 `reason` | `is not assessable and gives no reason` |
| 节点名不得含「薄弱/复习/巩固/加强/强化/专项/达标/过关」 | `carries [...]; that string is rendered on the television` |

> 最后一条容易被当成文案问题：节点名会作为 `review[].topic` **发到电视上**。家长页可以写「薄弱」，
> 孩子的屏幕不行。

### 1.6 覆盖（是否真的这批做完了）

`check_ability_coverage.py --strict` 只看一件事：每格能不能构造出四阶段。
`verdict` 四种：`missing`（0 题）、`partial`（缺某个难度）、`floor`（1/1/1）、`robust`（2/2/2 以上）。

## 2. B 层：门禁看不见的十条（**这才是要背的**）

每条都附了真实翻车现场。写完一批，用「自检问句」过一遍；答案是否，就改。

### B1 题必须自足：孩子手里没有课本

**翻车**：E6 第一版 36 道辨析题写成「关于珠峰，哪一句和课文一致」。题库是独立呈现的，
孩子没有原文可对照，**这种题无法作答**。整批返工重写。

**约束**：凡「阅读理解 / 辨析判断」线，题干必须自带引文或材料；「和课文一致」「根据课文」
这类问法一律不许出现。

**自检**：把这道题单独发给孩子，他手上只有屏幕——能答吗？

### B2「哪项不符」的干扰项，只能来自引文或由引文直接推出

**翻车**：E6 有 5 处。引文只说「他坐在轮椅上」，干扰项写「他不能走路」——本身是对的，
孩子按引文判断就会觉得它也不符，于是题有两个答案。

**约束**：干扰项要么是引文的直接矛盾，要么是引文的同义改写被改错。**不许出现「引文没提但本身正确」的选项。**

**自检**：每个干扰项，能不能指着引文里的一句说它错？

### B3 改题干必须同步改选项

**翻车**：C4 `d10` 辨析易原有题干与 `d02-q07` 一字不差，改成「三首诗的作者依次是」——
但选项还是旧的诗句配对，`tgt=2` 轮转后指向一个和问法无关的项。

**约束**：轮转脚本只重排、不校验语义。**改问法就是改题，选项必须跟着重写。**

**自检**：把正确选项单独读一遍，它回答的是现在这个问句吗？

### B4 同一批里同类题，题干必须各自带区分词

**翻车**：E1b 三道辨析题全叫「下面哪一句是正确的」，27 题里撞三处；C4 之后是第二次栽在重复上。

**约束**：同一批同一线同一难度的题，题干要有各自的区分点（「频度副词的位置正确」「enjoy 的用法正确」
「时态用对了」），不能共用一个泛称句式。

**自检**：把所有题干的第一句连起来读，像不像同一道题？

### B5 只有一个正确答案才配当选择题

**翻车**：E2 量词题 `a ___ of water`，`bottle` 和 `glass` 都对。

**约束**：出题前先自问「这个搭配是不是唯一的」。量词题要挑只对应一种量词的名词（bread/paper → piece）。

**自检**：四个选项逐个代入，有没有第二个读起来也通？

### B6 引文长度：题干上限 120，引文控制在 90 以内

**翻车**：E3/E4/E5 共 6 处超限，全是「读句子：“…”＋问句」整串超过 120。当前最长 `d12-q09` 是
119 字，**离上限差 1 个字**。

**约束**：按整串算长度，不是只算引文。引文给到 90 字以内，留给问句 30 字余量。
压缩引文时**不能剪掉解题必需的信息**（剪完要能重新解一遍）。

**自检**：`len(stem)` 多少？把引文去掉，剩下的问句还能独立成立吗？

### B7 选项里不放课本外的篇名；写人比写出处安全

**翻车**：C1b `d16-q06` 选项写了《过零丁洋》《示儿》《后出师表》，三篇都不在本册 outline，
被 1.5 的规则判 3 处失败。改成「这句话是谁说的（文天祥/陆游/李纲/诸葛亮）」。

**约束**：拿不准某篇在不在本册，就别写篇名。问作者、问人物、问朝代都比问出处安全。

### B8 轮转后正确答案的原文必须没变

**约束**：轮转只用「正确答案排首位 → 固定种子打散目标位 → 左轮换」这一套，
并且每轮都断言 `options[新位置] == 原正确项文本`。

**自检**：写入后抽三道，把 `k` 指向的选项打印出来读一遍。

### B9 数学：小数与百分数一律用 `Fraction`，禁止 float 直接 `==`

**翻车**：两次。`24.6 - 25 == -0.4` 为假；`550 / 500 * 100 == 110` 为假（得 110.00000000000001）。

**约束**：凡是除法、再乘 100、小数比较，一律 `Fraction(246,10) - 25 == Fraction(-2,5)`。

**自检**：`c` 里出现 `/` 或小数点了没有？出现了就换 `Fraction`。

### B10 开工前先看这个节点的存量题占的是什么

**翻车**：C3 `d06` 存量 3 题全占了「阅读理解」三档，补题只能补另外两条线；
C5 `d20` 三道存量都是「读某句、停顿正确的是」，新题再用同句式就像重复。

**约束**：按 `--detail` 的逐格缺口定题量，不按节点总数估。存量占满的线不补；
存量占用的句式换材料而不是换问法（断句题的选项本来就是切分方式，换问法反而会破）。

**自检**：这个节点已有的题，问法和材料分别是什么？我的新题和哪一道最像？

### B11 正确项不能是「唯一最长」的那一项

**翻车**：语文题库全库测一遍，正确项恰好是唯一最长选项的比例是 **68%**（存量 192 题是 72%）。
四个选项里挑最长的那个，就能拿到接近七成的正确率 —— 这不是难度的分布，是写题时"正确答案要说得准"
的自然结果：解释性的说法天然比错误说法长。孩子在电视上按两下就能摸出这个规律。

**约束**：写题时把四个选项的长度压在一个带内（最长不超过最短的 1.5 倍），并检查正确项不是唯一最长。
句式和选项语义不变，只调整措辞长短：给干扰项补足具体的限定词，或把正确项的修饰语砍掉。

**效果**：语文 C07–C11 这五批按此约束写，比例从 67% 降到 **13%**；其余 289 题（存量 192 + C01–C06 的 216 题
里不达标的部分）留作欠账，需要单独一轮改写选项措辞，不改答案与解析。

**自检**：四个选项的字数拉出来排一遍，最长的那个是正确项吗？如果是，改到不是。

## 3. C 层：B 里可以变成 A 的三条（尚未实现）

按性价比排序。三条都能在 `batch_spec.py` 里以 `rejects.append(...)` 的形式加，不写库。

| # | 规则 | 能抓到的 B | 误报风险 |
|---|---|---|---|
| C1 | 非数学题干含「读句子 / 读短文 / 根据课文 / 文中」但**没有引号内容** → 拒 | B1 | 低（引号是硬特征） |
| C2 | 题干里最长的 `"…"` / `“…”` 片段 > 90 字 → 拒 | B6 | 低（阈值来自实测：90 字 + 30 字问句） |
| C3 | 同一批内，`(node, ability, difficulty)` 相同的题，题干 `difflib` 相似度 > 0.85 → 拒 | B4 | 中（同材料不同问法可能误伤，需先跑存量验证） |

**无法自动化的两条**：B3（改题干没改选项，纯语义）、B5（第二个答案对不对，要人读）。
这两条只能靠 §2 的自检问句。

## 4. 一页 checklist（贴着屏幕用）

```
[ ] 这道题，孩子只有屏幕，能答吗？                    （B1）
[ ] 每个干扰项，都能指着一句引文说它错吗？            （B2）
[ ] 正确选项回答的是现在这个问句吗？                  （B3）
[ ] 这批同线的题，题干彼此看得出区别吗？              （B4）
[ ] 四个选项代入，有没有第二个也通？                  （B5）
[ ] len(stem) ≤ 120，且引文 ≤ 90 字？                （B6）
[ ] 选项里有课本外的篇名吗？能改成问人吗？            （B7）
[ ] k 指向的选项，原文是对的吗？                      （B8）
[ ] c 里有除法或小数吗？换成 Fraction 了吗？          （B9）
[ ] 这个节点的存量题，我已经看过问法和材料了吗？      （B10）
```

## 5. 附：两条不属于生题但会打断生题的事

1. **`git` 会解析到 `/usr/bin/git`** 并报 `requires a newer version of macOS`（本机 CLT 版本不匹配）。
   提交/推送失败时改用 `/Users/hey/.local/bin/git`（2.56.0）。
2. **`PLAN §7.2` 与代码漂移**：文档写「30 天内做过的题不再出」「每天 5 题」，代码实际是
   `limits.REPEAT_WINDOW_DAYS = 7`、每天上限 15 题。评估题量够不够时**以代码为准**，或先对齐这两处。
