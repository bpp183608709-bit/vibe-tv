# 实施笔记索引

这一目录放的是**二次开发过程中的复盘与经验**，与 `docs/` 下的规格文档分工不同：

| 目录 | 写什么 | 什么时候看 |
|---|---|---|
| `docs/` | 规格、架构、各机型的限制——描述系统**现在是什么样** | 改代码之前 |
| `notes/` | 为什么这么设计、真机上踩了什么坑、哪些结论是实测得来的 | 想理解某个决定，或准备做类似改造时 |

`docs/PARENTAL.md` 是家长模块的规格，改动行为应当先改它；本目录的复盘不替代规格。

## 清单

- [01 家长管控实现复盘](01-家长管控实现复盘.md) — 状态机、两条计时口径、播放信号三级判定、四个真机缺陷、防篡改时钟
- [02 真机适配与调试经验](02-真机适配与调试经验.md) — 设备差异、ADB 脚本陷阱、Compose 后台陷阱、磁盘统计口径、多语言文案
- [03 电视应用体检与清理](03-电视应用体检与清理.md) — 一次全量清理的分类方法、执行批次、实测回收与回滚
- [04 做题换时长：方案评审](04-做题换时长-方案评审.md) — 新方案的架构判断与风险清单，决策项见 `docs/待定事项-做题换时长.md`

## 本目录不包含

- 家庭网络拓扑、NAS 与自建下载服务的记录（属于另一个项目）
- 设备内网地址、设备标识、家长密码与管理员口令
- ADB 采集的原始快照（包列表、`diskstats`、`df` 输出）——留在本地，不入库

文中出现的 `<电视内网 IP>` 是占位符；本机真实地址只记录在本地私有文件中。
