# 备案没下来怎么办

> 写于 2026-11-17。前提：服务器在**中国内地**（阿里云 ECS，`47.95.198.148`），域名
> `quiz.qust.me`，备案预计 11-20 出结果，也可能不过。
>
> 这份文件只回答一件事：**如果没有备案，哪些事还能做、哪些不能、代价是什么。**
> 目的是让「降级」是一条配置改动，而不是一次代码改动或一次重装。

---

## 0. 先把两件事分开

备案管的是**域名**能不能在内地解析到内地服务器；它不管 IP 能不能访问，也不管证书。

所以：

| 事情 | 没有备案能不能做 | 依据 |
|---|---|---|
| 用 `https://47.95.198.148:8443` 打开家长页 | **能** | 没有域名，就没有需要备案的对象 |
| 电视用 `https://47.95.198.148:9443` 出题交卷 | **能** | 电视钉的是自家 CA，跟公信体系无关 |
| 用 `https://quiz.qust.me:8443` | **不能**（内地解析会被拦） | 域名指向内地 IP 而未备案 |
| 手机上没有一次证书警告 | 取决于证书，不取决于备案 | 见 §2 |

一句话：**产品的核心链路（电视做题、兑换时长）不依赖备案；受影响的只有家长手机上的那一次「继续访问」。**

---

## 1. 三条路，按代价从低到高

### 路 A：换个能备案的域名（推荐）

`.me` 能不能备案，以**阿里云备案控制台填进去的校验结果为准**——那里的校验就是最终标准，
不用去猜名单。如果它被驳回：

1. 买 `qust.cn` 或任意 `.com`（几十元/年）；
2. 用新域名重新提交备案（首次备案约 7–20 个工作日，各省不同）；
3. 备案通过后：`certbot` 签新证书 → `deploy.env` 加 `QUIZ_H5_CERT/QUIZ_H5_KEY` → 重启；
4. **APK 不用重出**：它钉的是 CA，不是域名；新证书的 SAN 加上新域名即可
   （`sh server/tools/make_ca.sh <新域名> 47.95.198.148` 重签一张叶子，CA 不变，电视照样认）。

代价：一段时间的等待 + 一个新域名的钱。收益：之后不再有这个问题。

### 路 B：用 IP + 一张「对 IP 也有效」的证书

备案失败且不想换域名时，H5 走 `https://47.95.198.148:8443`。此时证书有两选择：

- **自签（现在这张）**：手机第一次打开会拦一下，点「继续访问」后能正常用。缺点是每个新设备
  （换手机、清缓存、无痕窗口）都要点一次，而且家里老人会被吓住。
- **给 IP 签公信证书**：Let's Encrypt 已经开始签发 IP 证书，但需要能完成 ACME 校验，而且有效期很短
  （要自动续期）。**这一条要实测**：先确认当前账号与客户端支持，再决定是否值得。

代价：一次警告或一套自动续期；收益：今天就能用完整功能。

### 路 C：把 H5 挪到境外（不推荐）

换个境外机器放家长页，域名不备案也能解析。但：

- 家长页要读电视的数据，两个库就得跨地域同步或拆分，错题本会变成「两边不一致」；
- 内地手机访问境外小机器的稳定性，比证书警告更影响体验；
- 数据出境是另一件要论证的事。

这条路只在「H5 只给境外亲友用」时成立，和当前产品（一家人、一台电视）不符。

---

## 2. 现在就能做的三件事（不需要等备案结果）

1. **把降级做成配置。** `deploy/bin/app` 已经认 `QUIZ_H5_CERT` / `QUIZ_H5_KEY` 两个变量，
   换证书不用改代码；`QUIZ_H5_PORT` 换端口同理。443 与 8443 的切换是 `deploy.env` 一行。
2. **电视那条链路先通。** 9443 + 自签 CA 与备案完全无关，M1 可以照原计划做：
   `write_tv_config --base-url https://47.95.198.148:9443` → 重出 APK（带设备密钥）→ 家里真机跑通。
3. **证书 SAN 里始终留着 IP。** `make_ca.sh` 默认就把地址写进 SAN，所以「域名不通」时改一行
   baseUrl 就能退回地址，不用重签、不用重装。

## 3. 判断表

| 11-20 的结果 | 当天做什么 | 影响 |
|---|---|---|
| 备案通过 | `certbot` 签 `quiz.qust.me` → 加 `--listen 0.0.0.0:443` → DNS 指过去 | 手机无警告，地址变短 |
| 域名后缀被驳回 | 买 `.cn`/`.com` 重新备案；期间走 IP | H5 地址是 IP，电视不受影响 |
| 主体/资料问题 | 按驳回原因补材料再提交；期间走 IP | 同上 |
| 迟迟没有结果 | 走 IP 上线，备案当后台任务 | 同上 |

**无论哪种，电视端（M1）都不受影响，可以并行推进；受影响的只有家长页用哪个地址打开。**

---

## 4. 一条底线

备案没下来时，**不要把 `quiz.qust.me` 解析到内地这台机器并对外讲这个地址**：解析本身能生效，
但它是「未备案域名指向内地服务器」的典型形态，被抽查到是直接停解析，而不是警告。

要对外说地址，就说 IP。
