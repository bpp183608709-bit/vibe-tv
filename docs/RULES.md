# 数值规则：薄弱度 → 判档 → 配额 → 抽样

> **这份文档是什么**：错题训练功能里**所有数字的唯一出处**。每个常数、每张对照表、每条边界条件，
> 以及「改了这个数会动到什么」。
> **不是什么**：不是需求文档，也不是决策记录。为什么要有这个功能、为什么不给孩子看进度、
> 为什么不用概率模型，在 `docs/WRONGBOOK.md`（§2 产品判断、§16 决策台账）。本文只管数字。
>
> **两处出现同一个数字时，以本文为准**；发现不一致请改成一致，并把过程记进 §8。

## 0. 怎么用这份文档

| 你要做的事 | 看哪节 |
|---|---|
| 查某个常数是多少、在哪个文件 | §1 参数总表 |
| 想知道「为什么这个知识点 72 分」 | §2 |
| 想知道「为什么这轮 5 题里只出了 1 道错题」 | §3 |
| 想知道「三个薄弱点，为什么今天只出现一个」 | §4 |
| 想调参数 | §6 影响面 + §7 调参顺序，**不要跳过 §5 硬边界** |
| 想知道某个数是谁定的 | §8 |

**一句话数据流**：

```
答题事件 ──► 薄弱度 M（0–100）──► 档位 L0–L3
                                    │
                      ┌─────────────┴─────────────┐
                      ▼                           ▼
              档位数 n + 最差档 Lmax        档位签数 2/3/4
                      │                           │
                      ▼                           ▼
              五题怎么分（S0–S3）          错题段里抽谁（加权）
```

三件事依次决定，**后面的不会反过来影响前面的**：M 决定档位，档位决定配额和签数，配额和签数决定出什么题。

## 2. 规则一：薄弱度怎么涨、怎么降

### 2.1 事件权重

一个知识点一个整数 M。每个事件按固定权重加减，超出 0–100 截断。没有模型、没有遗忘曲线、没有拟合。

| 事件 | ΔM | 为什么是这个数 |
|---|---|---|
| 电视答错（未标记） | **+12** | 一次错就是一次明确信号 |
| 电视答对 | **−10** | 错一次要 1.2 次对才抵消，不对称是刻意的 |
| 连续答对第 2 次（追加） | **−10** | 让「连着对」有可见加速，一对共 −30 |
| 试卷错题，当天同知识点第 1 道 | **+20** | 纸上错的比屏幕上错的可信 |
| 试卷错题，当天第 2 道起 | **+8** | 递减：一张卷子不能把一个知识点顶满 |
| 家长手动调整 | **±10**（单次上限） | 家长更了解情况时的出口，但不能一键改写 |

> 试卷的「当天第几道」按该知识点算，不是按整张卷子算。判据是当天该知识点已登记的试卷错题条数（含本条）≤ 1。

### 2.2 两个例外（都围绕「没学过」标记）

| 情况 | ΔM | 理由 |
|---|---|---|
| 标记没学过 + **答对** | **0** | 说真话不罚也不奖；不写流水（没变化就不该有账） |
| 标记没学过 + **答错** | **+12** | 标记不能当免练卡，否则孩子会养成先点标记的习惯 |

两种标记都会把连对、连错计数清零——标记过的那次不是「学会了」，也不该往「卡住」上记。
但标记且答错的那次**照样计入连错**，参与暂停判断（暂停不是惩罚，是别再拿没教过的题去问他）。

### 2.3 档位

| 档 | 分数 | 签数 | 目标题量 | 每日上限 | 进错题段 |
|---|---|---|---|---|---|
| L0 | 0–11 | — | 0 | 0 | 否 |
| L1 | 12–35 | 2 | 5 | 3 | 是 |
| L2 | 36–70 | 3 | 7 | 3 | 是 |
| L3 | 71–100 | 4 | 10 | 3 | 是 |

**签数按档给，不按分数连续折算**。两个直接结果，写在这里免得每次都要重新推：

- 36 分和 70 分签数相同（都是 3 张），差 34 分而概率一样；
- 70 分和 71 分只差 1 分，签数从 3 跳到 4。

这是刻意的：连续映射没法向家长解释「为什么 40 分和 65 分概率不一样」，而档位边界本身的差别是真实的。

### 2.4 家长端的「再答对 N 次」

```
N = ceil((M − 11) / 10)        M ≤ 11 时为 0
```

常见值：12 分 → 1 次｜35 分 → 3 次｜70 分 → 6 次｜100 分 → 9 次。

**这个数故意不含连对加成**，所以孩子实际会比承诺的更早过关——做到了是惊喜，说少了才是骗人。
该值**只在 H5 出现**，不落库、不写进任何电视响应。

### 2.5 暂停

同一知识点连续答错 5 次 → 该知识点**暂停 3 天**，期间不进错题段。

- 暂停只影响「进不进错题段」，不影响课内出题；
- 触发后连错计数**立刻归零**。不归零的话第 6 次错会立刻再触发一次暂停，等于永久暂停；
- 已在暂停期内再次连错 5 次**不会延长**暂停（`_still_paused` 判断）。

## 3. 规则二：五题怎么分三段

每轮固定 5 道题，从三个来源取：**当前单元（C）**、**前几个单元（P）**、**错题段（R）**。

### 3.1 两个维度各判一档

| 维度 | 取值 → 档位 |
|---|---|
| 数量 `n` | 0 → S0｜1–2 → S1｜3–4 → S2｜5+ → S3 |
| 最差档 `Lmax` | 无 → S0｜L1 → S1｜L2 → S2｜L3 → S3 |

`n` **只数真能出题的**薄弱点：M ≥ 12、当前难度下近 7 天还有没出过的题、不在暂停期。
把一个出不了题的算进去，等于承诺一个填不上的坑。

### 3.2 判档矩阵（两个维度取较重）

| n \ Lmax | 无 | L1 | L2 | L3 |
|---|---|---|---|---|
| **0** | S0 | — | — | — |
| **1–2** | — | S1 | S2 | **S3** |
| **3–4** | — | S2 | S2 | **S3** |
| **5+** | — | S3 | S3 | S3 |

「—」是不可能出现的组合：没有薄弱点时最差档必为空，有薄弱点时最差档至少 L1。
`state_for` 在 `n = 0` 时直接返回 S0，不吃矛盾输入（自检里有断言）。两点值得记住：

- **一个知识点掉到 L3，不论总数多少，直接 S3**；
- **4 个 L1 和「3 个里含 1 个 L2」都是 S2**——数量和深度各自封顶，取高的那个。

### 3.3 配额

| 状态 | C 当前单元 | P 前单元 | R 错题段 |
|---|---|---|---|
| S0 | 5 | 0 | 0 |
| S1 | 4 | 0 | 1 |
| S2 | 3 | 0 | 2 |
| S3 | 2 | 1 | 2 |

**只有 C 和 R 两个旋钮，P 是余量**（P = 5 − C − R）。一个组只有 5 个位置，三个数不可能各自独立。

### 3.4 三条硬边界

| 边界 | 为什么 |
|---|---|
| **R ≤ 2** | 到 3 时科目轮转会把某一科的课内题挤掉，整组变成「又是那几个知识点」 |
| **C ≥ 2** | 这终究是一场考试，不是补习班 |
| **一组内同一知识点 ≤ 2 道** | 三个来源合计；再多就是同一道题换皮 |

### 3.5 快照：一天只算一次

当日第一组题时算好，写进 `daily_state`（`mix_state` / `mix_c` / `mix_r` / `mix_n` / `mix_note`），
当天所有组照用。否则孩子连错两道，R 立刻从 0 变 1，做对一道又变回去——他会觉得系统在抽风。

**一个例外**：当日有知识点新变薄弱（`topic_mastery.last_event_at` 落在当天），
即使快照是 R = 0，也临时给 1 位（C 4 / R 1），并写进快照。
否则「家长上午拍照录入、下午那组就该出现」要等到明天才成立。

### 3.6 供给不足时，坑要还回去

按顺序退让，任何情况下都**不重复出已出过的题来凑数**：

1. R 段抽不满 → 空位退回课内；
2. C 段达到 `c` 上限 → 多出来的给前单元；
3. 还需要 → 把 C 上限放开到 5 再补；
4. 仍不足 5 题但 ≥ 3 题 → 就发这个数（`MIN_GROUP_SIZE`）；
5. 少于 3 题或不足两科 → 报错，不发残缺组。

## 4. 规则三：错题段里抽谁

### 4.1 先过资格

进不了池子的三种情况（任一命中即排除）：

- M < 12（L0）；
- 当前处于暂停期；
- 当前难度下、近 7 天没有可出的题。

### 4.2 权重 = 签数 × 供给折扣

```
权重 W = 档位签数 × min(1, 池里还能出的题数 / 该档目标题量)
```

| 情形 | 签数 | 池里剩 | 折扣 | 实际 W |
|---|---|---|---|---|
| L2，目标 7，剩 7 | 3 | 7 | 1.00 | **3.0** |
| L2，目标 7，剩 3 | 3 | 3 | 0.43 | **1.29** |
| L3，目标 10，剩 5 | 4 | 5 | 0.50 | **2.0** |
| L1，目标 5，剩 1 | 2 | 1 | 0.20 | **0.4** |

**折扣的意义**：题库只剩 1 道的知识点，按原权重会天天被抽中，每次都是同一道题——孩子第二天就记住答案了。
宁可这次几乎不问，也不重复问。**补题的优先级因此高于调权重**（见 §7）。

### 4.3 抽签时权重还要按题均分

W 属于**知识点**，不属于每道题。抽签时每道题携带 `W / 该知识点在池中的题数`，
池子每抽走一道就重算分母。

不做这一步的话，一个题库里恰好有 10 道题的知识点会以 10 份权重压过只有 3 道题的更弱知识点——
决定频率的变成「题库恰好多大」，不是「孩子多弱」。实测差异：400 次抽样里 L3 曾占到 81%，修正后回到 67%。

### 4.4 抽签过程

- 无放回，一次抽一道（不是先洗权重再排序——同知识点上限和日上限会改变可选集合，洗牌会悄悄忽略它们）；
- 随机源是 `random.Random(now_ms)`，同一毫秒完全可复现；
- 抽满 R 个位或池子抽干为止。

### 4.5 三条限额（会挡住上面算出的概率）

| 限额 | 值 | 统计口径 |
|---|---|---|
| 一组内同一知识点 | ≤ 2 道 | 三个来源合计（`per_topic`） |
| 单知识点每天进错题段 | ≤ 3 道 | **按「次」不按「题」**，且算**已发出**的会话 |
| 同一道题重复出示 | 7 天内不再出 | `question` 的最近出现时间 |

**「按次不按题」这条必须照做**：用 `WHERE id IN (…)` 统计会把重复抽中的同一道题合并成一条，
于是「今天出了 4 次」被数成「3 道不同的题」，上限形同虚设。
**「已发出的会话」也要算**：否则反复开局就能刷到简单题。

### 4.6 孩子看到的顺序

抽完之后整组打乱（`shuffle`），错题不排在固定位置，也不在最后——否则孩子会记住「第三题总是英语」。

## 5. 不可违反的数值约束

改参数前逐条确认，这些不是风格问题，是正确性问题：

1. **M 全为 0 时，出题结果必须与引入本功能前逐题一致**。验收里有一份冻结的旧实现做逐 `question_id` 比对。
   这条依赖 `PREV_WINDOW[S0] == 2`，改成 3 会直接破掉。
2. **`mastery_event.delta` 记实际生效值**，不是名义权重。M 在 0 或 100 时 clamp 会吃掉差额，
   照抄名义值会让流水永远加不回 M。验收有一条「重放流水 == 存储分数」。
3. **`R_CAP ≤ 2` 且 `C ≥ 2`**，`QUOTA` 每行必须满足 C + P + R = 5。
4. **响应体字段集合完全冻结**：`/v1/quiz/next` 与 `/grade` 不许多出任何进度 / 知识点 / 段落字段。
   白名单写在 `server/tools/acceptance.py`，文本禁用词由 `server/tools/check_tv_silence.py` 全目录扫描。
5. **同一时刻可复现**：任何新的随机行为都必须挂在 `now_ms` 上，不许用 `random` 全局状态。
6. **`PER_TOPIC` 同时约束三个来源**。只约束错题段的话，课内段可以合法地把同一个知识点出 3 道。

## 6. 改参数的影响面

优化时照这张表查，**「连带」列里的测试不跑过就不算改完**。

| 参数 | 改小的直接后果 | 改大的直接后果 | 连带要改 |
|---|---|---|---|
| `WRONG_TV`（+12） | 答错推不进 L1，家长会觉得「错了但显示牢固」 | 一次错就接近 L2，权重与配额同时跳档 | `mastery` 自检；验收「错两道后档位」；§2.3 档位表不用改 |
| `RIGHT_TV`（−10） | 消降变慢，知识点停滞率上升 | 一次对就抵消一次错，错题池难以维持 | `mastery` 自检；`need_right` 表 |
| `STREAK_BONUS`（−10） | 连对加速消失，L3 清掉要 8–9 次 | 一对连对过猛，L1 可能一次就清 | 验收「一对共 −30」 |
| `WRONG_PAPER_*`（20/8） | 拍照录入变成无效操作 | 一张卷子把知识点顶满，配额直接跳到 S3 | 验收「试卷 20/8」；H5 文案「再答对 N 次」 |
| `PARENT_ADJUST`（10） | 家长修正力度不足 | 一键改写薄弱名单 | H5 调整按钮 |
| `WRONG_STREAK_PAUSE`（5） | 更容易暂停，家长看不到进展 | 孩子被同一类题卡住更久 | 验收「连错暂停」 |
| `PAUSE_MS`（3 天） | 暂停形同虚设 | 知识点整整一周不出现 | 验收、H5 状态文案 |
| `LEVEL_BOUNDS` | 档位边界移动，`need_right` 全部变化 | 同上 | **必须同步** `WEAK_MIN_SCORE`、§2.3、§2.4 示例、验收档位边界用例 |
| `LEVEL_WEIGHT_X10`（1/2/3/4） | 弱与更弱拉不开差距 | 最弱点垄断错题段 | `mix` 自检的 4:2 断言；验收的占比区间 |
| `LEVEL_TARGET_QTY`（0/5/7/10） | 供给折扣更严，题少的知识点更难被抽中 | 折扣更容易饱和 | 只影响折扣分母，不影响配额 |
| `LEVEL_DAILY_CAP`（0/3/3/3） | 日上限先卡住概率 | 单知识点一天可能出 4 道以上 | 验收「日上限 2→1→0」 |
| `QUOTA` | 配比表整体位移 | 同上 | `mix` 自检的求和断言；验收四档题数用例 |
| `PREV_WINDOW`（2 / S3 3） | **S0 改成 2 以外会破零回归** | 前单元窗口变宽，tier 判定变化 | 冻结参照实现 |
| `R_CAP`（2） | R 更保守 | **>2 会挤掉课内题位** | §3.4、验收占比 |
| `WEAK_MIN_SCORE`（12） | 与 `LEVEL_BOUNDS[0]` 脱钩，L1 进不了池 | L0 被算进薄弱名单 | 与档位边界必须同步 |
| `NEWCOMER_SLOTS`（1） | 今日录入当天看不到 | 破坏当日快照的意义 | 验收「今日新增占 1 位」 |
| `PER_TOPIC`（2） | 一组只有一个知识点 | 同一知识点刷屏 | 验收、`picker` 自检 |
| `GROUP_SIZE`（5） | 配比表全部重算 | 同上 | `QUOTA`、`MIN_GROUP_SIZE`、所有题数断言 |

**调参的乘法效应**：档位边界一动，配额表、签数、日上限、`need_right` 会同时变。
所以边界只在有明确理由时动，日常调优优先动签数和日上限。

## 7. 调参的推荐顺序

按「改动成本 / 可逆性」排，前面的能解决就不要动后面的：

1. **先看题量够不够**（补题、扩模板）。供给折扣说明很多「概率不对」其实是题不够，不是权重不对；
2. 调 `LEVEL_DAILY_CAP`：只说「一天最多出几道」，不改变长期比例，最容易回滚；
3. 调 `LEVEL_WEIGHT_X10`：改变薄弱点之间的相对频率，不影响配额；
4. 调 `QUOTA`：改变三段比例，影响最直观，也最容易被孩子察觉；
5. 调 `LEVEL_BOUNDS`：最后手段，一次改动会重算上面全部。

**每次只动一个参数，并保证能回答两个问题**：改之前预期哪个指标动、动多少；改之后实测是多少。
观测指标见 `docs/WRONGBOOK.md` §12（知识点停滞率 ≤15%、家长查看率 ≥50%）。

## 9. 已知取舍（不是缺陷，是选过的）

1. **L1–L3 的每日上限都是 3**。没有按档位区分强度，因为孩子感知不到区别，却会让「今天还能做几道」变得不可预测。
2. **签数只有 2/3/4 三档**，L1 与 L0 之间没有过渡。一个 12 分的知识点和一个 35 分的知识点概率相同。
3. **供给折扣会让最弱的知识点几乎不出现**（只剩 1 道题时权重 0.4）。这是有意的：重复同一道题的伤害大于少练。
4. **`n` 只数能出题的**，所以「家长看到 5 个薄弱点、系统只认 3 个」是正常现象。H5 需要标明哪些当前练不了。
5. **一组里同一知识点最多 2 道**（三个来源合计）。这限制了单轮强度，强度只能靠「次数」累积，不能靠「一道接一道」。
